# Campus Equipment Borrowing System

## Tech Stack
PHP, MySQL, HTML5, CSS3

## Included
- Equipment catalogue
- Borrow request form
- My Requests search/filter
- Admin request status update
- Equipment add/delete
- Prepared statements for user-input INSERT/UPDATE/DELETE/search queries
- MySQL schema and sample data

## Local setup
1. Install XAMPP.
2. Copy this folder into `htdocs`.
3. Start Apache and MySQL.
4. Open phpMyAdmin and import `database.sql`.
5. If your MySQL credentials differ, edit `db.php`.
6. Visit `http://localhost/campus_equipment_borrowing_system/`

## Important
This is an academic starter project. The Admin page is intentionally simple for demonstration; add login/authentication before using it for real-world deployment.
